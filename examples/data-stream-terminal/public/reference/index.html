Data Stream API Overview

This reference belongs to the example surface itself. It summarizes the current public behavior of the corto.fun data-stream API and stays self-contained for external users.

Runtime model

How clients should think about the stream

  • Service envelopes describe connection state and filter state.
  • Event envelopes carry public event payloads like create, buy, sell, and migration.
  • Pool-side lifecycle pages cover createPool, addLiquidity, removeLiquidity, and the reserved burn contract.
  • Some keys are always present, but their values can still be null by contract.
  • Null is not an error when the field is explicitly conditional.

Current honesty boundary

Important client assumptions

Burn Burn can be advertised before production burn events are emitted.
Letsbonk creator fee creatorFeeAddress can be null on a cold runtime or cache miss.
Conditional fields Any non-guaranteed value must be treated as optional by the client.
