Guarantee model

How to read field stability

Level Meaning
Key present The property is included in every object of that family.
Value reliable The client can treat the value as currently guaranteed on the supported path.
Value conditional The key is present, but the value can be null, transport-specific, pool-specific, or runtime-dependent.

Client messages

WebSocket request types

{
  "type": "subscribe",
  "mode": "all"
}
{
  "type": "subscribe",
  "mode": "mints"
}
{
  "type": "subscribe",
  "events": ["create"],
  "pools": ["letsbonk.fun"],
  "create": {
    "detail": "mid"
  }
}
{
  "type": "unsubscribe",
  "events": ["trade"],
  "pools": ["letsbonk.fun"]
}
{
  "type": "current_state"
}
  • If mode is present, the server expands it into the effective filter automatically.
  • Supported quick modes are all, mints, trades, migrations, and pools.
  • Mode must not be combined with events or pools in the same message.
  • If events are omitted, the request means all currently deliverable events.
  • If pools are omitted, the request means all currently available pools.
  • The trade alias expands to buy plus sell.
  • Create detail is an optional layer on the same subscribe path. Public values are min, mid, and full.

Create contract note

Create can be quote-aware

  • SOL quote create paths expose solAmount, solInPool, vSolInBondingCurve, and marketCapSol.
  • Non-SOL launchpad create paths expose quoteInPool, vQuoteInBondingCurve, and marketCapQuote instead of pretending the same values are SOL.
  • Clients should branch on quoteMint rather than assuming every create pair is SOL-based.

subscription_ack Confirmation after subscribe or unsubscribe changes
current_state Snapshot of current filter and upstream state

Client rule

Do not over-assume

  • Read schemaVersion and txType before branching.
  • Treat null as a valid contract outcome for conditional values.
  • Adjacent event pages use current contract examples taken from observed payloads or current builder fixtures.
  • Do not assume historical or experimental pool paths exist just because they exist elsewhere in the repository.
