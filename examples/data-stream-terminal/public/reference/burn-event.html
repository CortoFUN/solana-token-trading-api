Burn Event Reference

Burn is reserved as a separate pool-side lifecycle event. It is not a synonym for removeLiquidity and it is not yet a production observed public stream payload.

Honesty boundary

No observed public payload yet

  • The runtime may advertise burn as subscribable.
  • The current builder still emits zero production burn events.
  • Public clients should treat burn as not ready for production extraction yet.

Client rule

Do not treat burn as live data yet

  • Do not build production analytics that assume burn events are currently emitted.
  • Do not collapse burn into removeLiquidity in your own parser.
  • Wait for a future observed payload rollout before treating burn as live extractable surface.

Schema notes

Why the page exists now

  • The contract is already reserved in SSOT and runtime surface.
  • The example documents the intended shape, but not an invented on-chain payload.
  • This keeps the public docs honest until real production burn examples exist.
