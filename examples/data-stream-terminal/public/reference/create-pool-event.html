CreatePool Event Reference

CreatePool events describe the moment a target pool account is created. They are pool-side lifecycle events, not launch-side create events.

Guaranteed core

Fields clients can rely on

  • signature, mint, txType, pool, poolId
  • source, slot, block, poolProgramId, instructionName, hasError
  • baseVault, quoteVault, baseMint, quoteMint

Conditional values

Do not over-assume

  • poolCreatedBy is lineage-sensitive, not universally guaranteed.
  • price exists only when both sides are proven from the current transaction.
  • lpMint and initial liquidity amounts are contract fields, but still conditional values.
